# Miftahul Arif — Portfolio

Personal portfolio website for **Miftahul Arif**, focused on digital solutions, web applications, business process automation, reporting workflows, and AI-assisted development.

## Featured project

### Employee Activity & Attendance Reporting System

A real internal administrative web application built to move a repetitive spreadsheet/document reporting process into a structured workflow.

**Stack**
- HTML / CSS / JavaScript
- Supabase / PostgreSQL
- Supabase Auth
- Row Level Security (RLS)
- Cloudinary
- docx.js
- Git / GitHub

**Key areas**
- Employee and admin access
- Monthly reporting
- Activity and attendance records
- Media upload
- Structured relational data
- Ownership-based authorization
- Automated Word output

## Run locally

This is a static website. No build step is required.

```bash
git clone https://github.com/1997miftahularif/miftahul-arif-portfolio.git
cd miftahul-arif-portfolio
```

Open `index.html` in a browser, or use any static local server.

## Deploy to Vercel

### Option A — GitHub integration
1. Create a new GitHub repository.
2. Upload the contents of this folder.
3. Import the repository into Vercel.
4. Keep the framework preset as **Other** / static.
5. Deploy.

No environment variables are required for this portfolio site.

### Option B — Vercel CLI

```bash
npm i -g vercel
vercel
```
