CASE STUDY / 01

Employee Activity & Attendance Reporting System

A web application for moving a repetitive monthly reporting process from spreadsheets and manual document preparation into a structured digital workflow.

HTMLCSSJavaScriptSupabase PostgreSQLAuthRLSCloudinarydocx.js

The problem

Employees submitted activity and attendance information through a repetitive manual process. Administration then had to collect, organize, document, and prepare monthly reports.

The solution

A structured web application where employees submit records and administrators can manage reporting workflows, while media and final Word documents are handled digitally.

Data & security

Supabase/PostgreSQL provides relational storage. Authentication identifies users, while Row Level Security supports ownership-based authorization and separate administrative access.

Output

Submitted activity and attendance data can be transformed into a templated Word document, reducing repetitive document preparation.

WORKFLOW

Employee Login→ Submit Activity / Attendance→ Supabase / PostgreSQL→ Cloudinary Media→ Admin Access→ Word Output

WHAT I BUILT

Frontend

Responsive HTML/CSS/JavaScript interface for report submission and administration.

Database

Relational structure for employees, reports, activities, and attendance with indexes and constraints.

Authorization

Supabase Auth and RLS policies for user ownership and admin access.

Documents

Automated Word generation using docx.js from structured application data.

PROJECT NOTE

This project demonstrates end-to-end workflow thinking: understanding the source process, designing structured data, implementing access control, connecting media storage, and producing a usable document output.
